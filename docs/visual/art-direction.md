# M0 · ทิศทางภาพหอคอยสี่วิชา

**สถานะ: concept** — กฎภาพสำหรับฉากนำร่อง Hub; ยังไม่มีภาพชุดใหม่ที่ผ่าน visual QA

## แนวทางเดียว: ลานเรียนรู้ที่ชวนสำรวจ

ลานกลางเป็นสวนหินและอาคารเวทมนตร์ขนาดเล็ก ให้ทางเดินกับจุดโต้ตอบเด่นกว่าของตกแต่ง ตัวละครมีเส้นขอบเข้ม รูปร่างและอุปกรณ์อ่านออกเมื่ออยู่บนจอมือถือ ใช้รูปทรงและสัญลักษณ์ที่สร้างขึ้นสำหรับเกมนี้เท่านั้น ไม่คัดลอกองค์ประกอบเฉพาะของเกมอื่น ภาพสำหรับเด็ก ป.6 ใช้ความขัดแย้งเชิงแฟนตาซีที่ไม่รุนแรง

## สัญญาที่ตรวจจากรีโป

- ไทล์ไอโซเมตริก **64×32 px**; ศูนย์กลางไทล์อยู่ที่ `isoToWorld(tx, ty)` ตาม `src/shared/iso.ts` และ Tiled object ใช้พิกัดแกนละ 32 px ก่อนหัก 0.5 ไทล์
- แผนที่ปัจจุบัน `hub.json` เป็น 23×23 ไทล์, `orientation: isometric`, tileset 21 เฟรมเรียงแนวนอน, GID เริ่มที่ 1; Phaser วาด `ground` และ `decor_below` ลง render texture, ไม่ใช้ tilemap renderer ตรง ๆ
- ตัวละครที่มีอยู่ใช้เฟรม **48×64 px**, 4 แถว `down,left,right,up`, แถวละ 10 เฟรม: idle 0–1, walk 2–5, attack 6–7, hurt 8, victory 9; origin ที่เท้า `(0.5, 0.94)` และเรียงความลึกด้วย world Y
- วัตถุใน `occluders` และ `transitions` เรียงความลึกตาม world Y; `above` อยู่เหนือทุกตัวละครด้วย depth คงที่ 100000; จุดชนใช้ค่าใน tile layer `collision` ไม่ได้คำนวณจากขอบภาพ
- เกมใช้ `pixelArt`, ปิด antialias, เปิด `roundPixels`, `Phaser.Scale.RESIZE`; กล้อง zoom ขั้นละ 0.5 ในช่วง 1–3; มี WebGL และ Canvas fallback (`?renderer=canvas` ใช้ตรวจ)
- React/CSS แสดงข้อความภาษาไทยและ HUD ทับฉาก: Sarabun สำหรับเนื้อหา, Mitr สำหรับหัวข้อ; ปุ่มขั้นต่ำ 44×44 CSS px, safe area, focus/disabled และ reduced motion มีอยู่แล้ว

## กฎภาพสำหรับ asset ถัดไป

- รักษากริดและ origin ข้างต้นจนกว่า renderer กับทีมระบบจะตกลงแก้สัญญา; ทุก sprite ต้องมีพื้นที่โปร่งใสที่ไม่ทำให้เท้าขยับระหว่างเฟรม
- เส้นขอบเข้ม `#1d1a2b`, ตัวละครสว่างกว่าพื้นหลังใกล้เท้า, พื้นทางเดินให้คอนทราสต์กับหญ้า/ฉาก; แสงหลักอุ่นจากด้านซ้ายบนและเงาสั้น ไม่ใช้ glow ใหญ่ปิดทางเดิน
- วิชาใช้สีร่วมกับไอคอนและชื่อ: คณิต `#3b82f6`, ไทย `#3fb950`, วิทย์ `#f0883e`, อังกฤษ `#a371f7` (ค่าปัจจุบันจาก `src/ui/styles.css` และตัวสร้าง tile); ห้ามใช้สีอย่างเดียวแยกทาง
- ข้อความไทยยาวและสถานะ UI เป็น React text ไม่ฝังลง PNG; ฉากต้องปล่อยพื้นที่อ่านโจทย์บนมือถือ และไม่ให้ปุ่มหรือ HUD บังจุดโต้ตอบสำคัญ
- ไฟล์ใหม่ต้องระบุแหล่งที่มา/สิทธิ์, ขนาด, frame, origin และสถานะใน manifest ก่อนเชื่อมเกม; AI concept ต้องตรวจพิกเซล/กริด/เฟรมจริงก่อนเปลี่ยนเป็น `integration-ready`

## ฉากนำร่องและเกณฑ์ผ่าน

ใช้ **Hub เส้นทาง spawn → อาจารย์ฮูก/กระดานภารกิจ → ประตูคณิต** ตาม `docs/visual/scenes/hub-pilot.md` เป็นฉากเดียวของรอบแรก ตรวจที่ 360×800 และ 1366×768 ทั้ง WebGL/Canvas: ผู้เล่นอ่านออกจากพื้น, เดินผ่านหน้า–หลังเสา/ต้นไม้ถูกชั้น, ทางเดินและจุดโต้ตอบมองเห็น, ไม่ติด collision ที่ขอบ, ป้ายไทยไม่ล้นหรือบังตัวละคร และฉากยังเล่นได้เมื่อเปิด UI โจทย์

**ข้อจำกัด M0:** ภาพอ้างอิง `docs/references/onet-pixel-rpg-concept.png` ยังไม่มี; asset ปัจจุบันทั้งหมดเป็น placeholder ที่สร้างด้วย `tools/assets/generate-placeholders.ts` จึงยังไม่ล็อก palette หรือคุณภาพภาพสุดท้ายจาก reference
