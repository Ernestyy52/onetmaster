## เกณฑ์ M1 และข้อจำกัดของผลตรวจ

- **ผ่านสำหรับแพ็กเกจภาพ M1:** concept 5 บทบาทอ่านแยกได้ที่กรอบ 48×64; UI สร้างตัวและอาชีพอ่านได้บนมือถือ; body/overlay มีกริดและ anchor ตรง manifest; ภาพตัวละครกับอุปกรณ์แสดงร่วมกันใน Hub/Battle/portrait; ไอคอนอาชีพตรงบทบาท. `npm run lint`, `npm run typecheck` และ unit tests 56 ข้อผ่าน
- **ต้องตรวจเมื่อมีอุปกรณ์/ภาพตัวจริง:** เซฟทดสอบมีเพียงอุปกรณ์เริ่มต้น จึงยังไม่เห็น `mace`/`staff`/`bow` ในกระเป๋าและยังไม่เล่น animation ทุกทิศกับ overlay ทุกชนิด. `player_mage` ยังมีชุด/ไม้เท้าติด body; อย่าใช้กับ overlay โดยตรง. ภาพ placeholder และ concept ยังไม่ใช่ final art
- **ต้องใช้อุปกรณ์จริง:** safe area ของมือถือที่มีขอบเว้า/แถบ Home. เบราว์เซอร์ 360×800 ไม่จำลอง inset นี้. การตรวจ keyboard/focus ทุกเส้นทางและ contrast เชิงตัวเลขเหมาะกับ QA ข้ามเกมใน M6
- การเปลี่ยนอาชีพหลังจบบทนำเป็นเส้นทาง gameplay ที่ unit/e2e ของ Claude ดูแล; รอบภาพนี้ตรวจแผงอาชีพและไอคอนบนเซฟที่ยังไม่ปลดล็อก
