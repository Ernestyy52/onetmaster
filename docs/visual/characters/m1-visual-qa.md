## สิ่งที่ต้องทำเพิ่มในงานภาพ

1. **Safe area หน้าสร้างตัว:** หน้าปัจจุบันอยู่ครบใน viewport ที่ตรวจ แต่ `.screen` ใช้ `padding: 16px` โดยไม่บวก `safe-area-inset-*`; ควรบวก inset และตรวจบนมือถือที่มีขอบเว้า/แถบ Home. การทดสอบ viewport ในเบราว์เซอร์ยังยืนยัน safe area ของเครื่องจริงไม่ได้
2. **ชั้นภาพอุปกรณ์:** ตัวฐานไม่มีอาวุธติดภาพแล้ว; ต้องคงลำดับ `armor → shoes → charm → weapon`, เฟรม/origin เดียวกันใน Hub, Battle และ portrait. ตัวอย่างที่สวมเสื้อคลุม+ดาบไม้ดูตรงกันใน Hub/HUD; ยังต้องดูตอนเดิน/โจมตีทุกทิศและเมื่อเดินหน้า–หลังเสา/ต้นไม้. `player_mage` ยังมีชุดและไม้เท้าติด body จึงไม่ควรนำมาใช้กับ overlay โดยตรง
3. **ตรวจไอคอนไอเทมใหม่ใน UI จริงเมื่อมีไอเทม:** atlas/key ตรงกัน และแผงอาชีพที่ 360×800 ผ่านแล้ว; เซฟทดสอบปัจจุบันมีเพียงไอเทมเริ่มต้น จึงยังไม่เห็น `mace`/`staff`/`bow` ในกระเป๋าหลังเปลี่ยน atlas

## ยังไม่ตรวจ

การเปลี่ยนอาชีพหลังจบบทนำ, overlay ทุกชนิดระหว่าง animation 4 ทิศ/การโจมตี/การบังหลังฉากในทั้งสอง renderer, safe area บนอุปกรณ์จริง, keyboard/focus ทุกเส้นทาง และ contrast วัดเชิงตัวเลข. ภาพผู้เล่นและอุปกรณ์ยังมีสถานะ `placeholder` ใน runtime manifest; ผลข้างต้นไม่ได้รับรองว่าเป็นภาพสุดท้าย
