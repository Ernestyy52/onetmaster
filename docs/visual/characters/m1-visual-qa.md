## จุดส่งต่อ Claude

1. **ไอคอนอาชีพยังสื่อความหมายคลาดเคลื่อน:** `guardian` ใช้ `robe`, `mage` ใช้ `book`, `archer` ใช้ `gear` จาก icon atlas เดิม; screenshot มือถือเห็นเป็นเสื้อ/หนังสือ/เฟือง ขณะที่บทบาทคือโล่/คทา/ธนู. ชื่อข้อความยังชัด จึงไม่ขวาง M1 แต่ควรเพิ่มไอคอน `shield`, `staff`, `bow` ต้นฉบับในรอบ asset ถัดไป พร้อมแก้ atlas generator, `ICON_NAMES` และ `JOBS.icon` ด้วยกัน ห้ามเปลี่ยนเฉพาะ key แล้วปล่อย atlas ไม่ตรงลำดับ
2. **หน้าสร้างตัวและเลือกตัว:** คำเรียกรูปลักษณ์เปลี่ยนเป็นชุดแล้ว และ Job แสดงแยกจาก Look ตามสเปก. รักษาความต่างนี้เมื่อเพิ่มภาพตัวละครจริง
3. **ยังไม่ตรวจ:** การเปลี่ยนอาชีพหลังจบบทนำ, keyboard/focus ทุกเส้นทาง, safe area บนอุปกรณ์จริง, Canvas fallback, sprite 4 ทิศ/animation. ปุ่มเปลี่ยนอาชีพยังปิดอยู่ตามเงื่อนไขบทนำในเซฟทดสอบ

การตรวจวัด: `document.documentElement.scrollWidth` เท่ากับ 360 px ในหน้าเลือก/สร้างและแผงอาชีพ; ปุ่มหลักกับปุ่มกลับ/การ์ดที่กดได้สูงอย่างน้อย 44 CSS px. หน้าเลือกกลับเข้าได้จากเมนูในเกม → `เปลี่ยนตัวละคร`; ชื่อซ้ำทดสอบด้วยตัวละครตัวแรกในข้อมูลทดสอบของเบราว์เซอร์
