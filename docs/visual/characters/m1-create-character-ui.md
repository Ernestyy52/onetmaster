# M1 · สัญญาภาพหน้าสร้าง/เลือกตัวละคร

**สถานะ: สเปก UI ที่ตรวจเทียบกับ M1 แล้ว** — ภาพ concept แยกอยู่ใน `m1-character-spec.md`; ไฟล์นี้ไม่ใช่ React implementation

## ลำดับหน้าจอ

1. **เลือกช่องตัวละคร:** แสดงช่องที่มีตัวละครด้วย portrait จาก `Appearance`, ชื่อเล่น, Adventure Level และ Job label; ช่องว่างมีปุ่ม `สร้างตัวละคร`. ระบุช่องที่เลือกด้วยกรอบและข้อความ ไม่ใช้สีอย่างเดียว
2. **สร้างตัวละคร:** ชื่อเล่น → เพศ (`ชาย`/`หญิง`) → ตัวอย่างภาพใน `ชุดพื้นฐาน` พร้อมอุปกรณ์เริ่มต้นที่สวม → ปุ่มยืนยัน. ไม่มีตัวเลือกชุดใน M1; เพศไม่กระทบค่าสถานะ. เริ่มเป็น `novice` เสมอ; ข้อความกำกับ `เลือกอาชีพได้หลังจบบทนำ` เพื่อไม่ให้ชื่อ asset เดิม `player_swordsman` ถูกเข้าใจว่าเป็นอาชีพ
3. **เปลี่ยนอาชีพ:** หลังระบบปลดล็อกแล้ว แสดง 4 การ์ดพร้อมชื่อ/ไอคอน/บทบาทสั้นและสถานะเลือก; ใช้ภาพ concept นี้เป็นแนวทางศิลป์เท่านั้น ระยะ M1 ให้ใช้ portrait เดิมกับป้ายชื่อ/ไอคอน ไม่โหลดภาพ concept เข้าเกม

## Layout และสถานะ

| พื้นที่ | Desktop ≥900 CSS px | มือถือ 360×800 |
| --- | --- | --- |
| รายการช่อง | การ์ดเรียง 3 ช่องในกรอบกลาง ไม่เกินความกว้างอ่านง่าย | การ์ดเรียงแนวตั้ง เลื่อนภายในหน้าจอได้ |
| ภาพตัวอย่าง | portrait ขยายด้วย `image-rendering: pixelated`; body + overlay ใช้เฟรมเดียวกัน; ชื่อ, เพศ/ชุดพื้นฐาน และอาชีพแยกบรรทัด | portrait อยู่ข้างข้อความโดยไม่บังปุ่มยืนยัน |
| ตัวเลือก Appearance | เพศ 2 การ์ดใน fieldset เดียว; ชุดพื้นฐานเป็นข้อความกำกับ | การ์ดกว้างพอแตะ; selected ของเพศชัดและมีชื่อกำกับ |
| ปุ่มหลัก | ด้านล่างกรอบตาม flow เดิม | อยู่หลังเนื้อหาและพ้น safe area; แตะได้ ≥44×44 CSS px |

- สถานะที่ต้องเห็น: `selected`, `focus-visible`, `disabled/busy`, ชื่อไม่ผ่านกฎ, ชื่อซ้ำ, ช่องเต็ม, โหลด/บันทึกสำเร็จ. ข้อความผิดพลาดอยู่ใกล้ช่องชื่อและอ่านได้โดย screen reader; ไม่ฝังข้อความลง PNG
- ทุกการ์ดที่กดได้ต้องมีชื่อที่อ่านออกและพื้นที่แตะ ≥44×44 CSS px; portrait ตกแต่งควรมีข้อความเทียบเท่าใน DOM. อย่าแสดงข้อมูลเด็กเกินชื่อเล่นกับความคืบหน้าที่จำเป็น
- พื้นหลัง/ขอบ/ฟอนต์ใช้ token เดิมจาก `src/ui/styles.css`: panel เข้ม, ขอบอ่อน, accent ทอง, Sarabun/Mitr. สีอาชีพเป็นเพียง accent ไม่แทนชื่อหรือรูปทรง

## จุดต้องประสานกับ Claude

บน branch M1 หน้าเลือกเพศ, preview ชุดพื้นฐาน และไอคอนอาชีพ `shield`/`staff`/`bow` ทำแล้ว. หน้าสร้างตัวอยู่ครบใน viewport 360×800 และ 1366×768; `.screen` กับ `.modal-backdrop` บวกระยะ `safe-area-inset-*` แล้ว. การทดสอบบนเบราว์เซอร์ยังไม่แทนการตรวจขอบเว้าบนอุปกรณ์จริง. ผลตรวจเพิ่มเติมอยู่ใน [M1 visual QA](m1-visual-qa.md). หลีกเลี่ยงการนำภาพ concept ไปแสดงแทน sprite จริง
