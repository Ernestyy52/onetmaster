# M1 · สัญญาภาพหน้าสร้าง/เลือกตัวละคร

**สถานะ: concept** — สเปกให้ Claude เชื่อมกับ UI เดิม ไม่ใช่ React implementation

## ลำดับหน้าจอ

1. **เลือกช่องตัวละคร:** แสดงช่องที่มีตัวละครด้วย portrait จาก `Look`, ชื่อเล่น, Adventure Level และ Job label; ช่องว่างมีปุ่ม `สร้างตัวละคร`. ระบุช่องที่เลือกด้วยกรอบและข้อความ ไม่ใช้สีอย่างเดียว
2. **สร้างตัวละคร:** ชื่อเล่น → รูปลักษณ์ → ตัวอย่างภาพ → ปุ่มยืนยัน. เริ่มเป็น `novice` เสมอ; ข้อความกำกับสั้น `เลือกอาชีพได้ภายหลัง` เพื่อไม่ให้ portrait เดิมชื่อ `player_swordsman`/`player_mage` ถูกเข้าใจว่าเป็นอาชีพ
3. **เปลี่ยนอาชีพ:** หลังระบบปลดล็อกแล้ว แสดง 4 การ์ดพร้อมชื่อ/ไอคอน/บทบาทสั้นและสถานะเลือก; ใช้ภาพ concept นี้เป็นแนวทางศิลป์เท่านั้น ระยะ M1 ให้ใช้ portrait เดิมกับป้ายชื่อ/ไอคอน ไม่โหลดภาพ concept เข้าเกม

## Layout และสถานะ

| พื้นที่ | Desktop ≥900 CSS px | มือถือ 360×800 |
| --- | --- | --- |
| รายการช่อง | การ์ดเรียง 3 ช่องในกรอบกลาง ไม่เกินความกว้างอ่านง่าย | การ์ดเรียงแนวตั้ง เลื่อนภายในหน้าจอได้ |
| ภาพตัวอย่าง | portrait ขยายด้วย `image-rendering: pixelated`; ชื่อและอาชีพแยกบรรทัด | portrait อยู่เหนือ/ข้างข้อความโดยไม่ดันปุ่มยืนยันพ้นจอ |
| ตัวเลือก Look | สองการ์ดเดิม แต่ใช้ชื่อเป็นรูปลักษณ์ ไม่ใช่อาชีพ | สองการ์ดกว้างพอแตะ; ถ้าแคบให้เรียงตั้ง |
| ปุ่มหลัก | ด้านล่างกรอบตาม flow เดิม | อยู่หลังเนื้อหาและพ้น safe area; แตะได้ ≥44×44 CSS px |

- สถานะที่ต้องเห็น: `selected`, `focus-visible`, `disabled/busy`, ชื่อไม่ผ่านกฎ, ชื่อซ้ำ, ช่องเต็ม, โหลด/บันทึกสำเร็จ. ข้อความผิดพลาดอยู่ใกล้ช่องชื่อและอ่านได้โดย screen reader; ไม่ฝังข้อความลง PNG
- ทุกการ์ดที่กดได้ต้องมีชื่อที่อ่านออกและพื้นที่แตะ ≥44×44 CSS px; portrait ตกแต่งควรมีข้อความเทียบเท่าใน DOM. อย่าแสดงข้อมูลเด็กเกินชื่อเล่นกับความคืบหน้าที่จำเป็น
- พื้นหลัง/ขอบ/ฟอนต์ใช้ token เดิมจาก `src/ui/styles.css`: panel เข้ม, ขอบอ่อน, accent ทอง, Sarabun/Mitr. สีอาชีพเป็นเพียง accent ไม่แทนชื่อหรือรูปทรง

## จุดต้องประสานกับ Claude

บน branch M1 การ์ดรูปลักษณ์เปลี่ยนเป็น `ชุดนักผจญภัย` และ `ชุดคลุมเวท` แล้ว. `src/ui/icons.ts` ยังไม่มี shield/bow/staff; ไอคอนอาชีพที่ใช้แทนบางตัวสื่อความหมายคลาดเคลื่อนตาม [ผลตรวจ UI](m1-visual-qa.md). ช่วง M1 ให้คงชื่อข้อความชัดเจน และทำไอคอนต้นฉบับชุดเล็กหลังตกลงสัญญา atlas. หลีกเลี่ยงการนำภาพ concept ไปแสดงแทน sprite จริง
