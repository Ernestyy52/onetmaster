# Hub pilot · ผังตรวจภาพ M0

**สถานะ: concept** — สเปกตรวจฉากเดิม ยังไม่มีแผนที่หรือภาพใหม่

## ผังที่ใช้อยู่จริง

`public/assets/maps/hub.json`: 23×23 ไทล์, 64×32 px, เส้นแกนทางเดินเชื่อมสี่ประตูผ่านตรากลาง. Tiled object `(x,y)` แปลงเป็นไทล์ด้วย `(x/32 - 0.5, y/32 - 0.5)` แล้ว renderer ปัดเป็นจำนวนเต็มสำหรับ object ส่วนใหญ่

| จุด | ชื่อ object ใน Tiled | ไทล์ `(tx,ty)` | การใช้ในฉาก |
| --- | --- | --- | --- |
| เกิดผู้เล่น | `spawns/player_spawn` | `(12,12)` | เริ่มตรวจ silhouette และ HUD |
| อาจารย์ฮูก | `spawns/npc_owl` | `(13,9)` | NPC และป้ายภาษาไทย |
| กระดาน | `spawns/quest_board` | `(9,9)` | จุดโต้ตอบและทางเข้าถึง |
| ประตูคณิต | `transitions/door_math` | `(11,1)` | เป้าหมายเส้นทาง; มี `subject=math`, `sprite=door_math`, `target_scene=room_math` |
| บอสบทนำ | `spawns/boss_gear_warden` | `(11,4)` | แสดงเฉพาะสถานะเควสต์ที่กำหนด |

อีกสามประตูอยู่ที่ ไทย `(1,11)`, วิทย์ `(21,11)`, อังกฤษ `(11,21)`; เก็บสีและสัญลักษณ์ให้ต่างกัน แต่ยังไม่ผลิตพื้นที่วิชาใน M0

## ชั้นภาพและจุดชน

| Layer | ชนิด | ข้อกำหนดที่ renderer ใช้ |
| --- | --- | --- |
| `ground` | tile | พื้นหลัก; วาดก่อนทุกอย่าง |
| `decor_below` | tile | ตรา/พื้นสี; วาดรวมกับ ground |
| `collision` | tile, hidden | GID ไม่เป็น 0 คือเดินไม่ได้; ปัจจุบัน 156 จาก 529 ช่อง |
| `occluders` | object | prop มี `sprite`; วาง origin จาก manifest และ depth = world Y |
| `spawns` | object | ชื่อเฉพาะที่ renderer อ่านสำหรับ player, owl, board, enemy, boss |
| `transitions` | object | ต้องมี `subject` และ `sprite`; ภาพประตูใช้ depth = world Y |
| `above` | object | `sprite`, `height`, `float`; แสดงเหนือตัวละครด้วย depth 100000 |

Collision ของ prop/ประตูถูกฝังใน `collision` layer โดยตัวสร้างแผนที่; property `collide` ของ object ไม่ใช่ตัวตัดสินการเดินใน renderer ปัจจุบัน จุดโต้ตอบใช้ระยะ world px (ปกติ 60, ประตู 72, บอส 90) และเดินไปช่องว่างรอบ object เมื่อต้องเข้าใกล้

## เกณฑ์ตรวจรับฉากนำร่อง

1. จาก spawn เดินถึง owl, board และประตูคณิตได้ โดยไอคอน/ป้ายและขอบทางไม่กลืนกับพื้น; ทดสอบแตะและคีย์บอร์ด
2. เดินหน้า–หลังต้นไม้และเสาอย่างน้อยชนิดละหนึ่งจุด ตรวจ depth ตามตำแหน่งเท้า และโคม `above` ไม่ตัดตัวละครผิดชั้น
3. ตรวจ NPC/กระดาน/ประตูไม่ทับ HUD หรือการ์ดโจทย์ที่ 360×800 และ 1366×768; ลอง `?renderer=canvas` ด้วย
4. บันทึกภาพก่อนและหลังเปิดประตูคณิต; ป้าย/รูปร่าง/สีสื่อสถานะโดยไม่พึ่งสีอย่างเดียว

## สิ่งที่ audit พบและสถานะ M1

- M0 พบ manifest ระบุ `hub` 22×22 แต่ JSON จริง 23×23; M1 แก้ manifest และตัวสร้างให้เป็น 23×23 แล้ว
- M0 พบ `occluders` มีชื่อซ้ำ 4 ค่า; M1 ลบต้นไม้ซ้ำที่มุมแล้ว. ตรวจ JSON ปัจจุบันพบ `occluders` 54 object และไม่มีชื่อซ้ำ
